# میزکار زندگی 🗂️

> وب‌اپ شخصی فارسی برای مدیریت یکپارچه‌ی وظایف، تقویم شمسی، عادت‌ها، یادداشت‌ها و مالی (اختیاری) — کاملاً آفلاین و در مرورگر خودتان.

تمام داده‌ها فقط در `localStorage` مرورگر ذخیره می‌شوند؛ هیچ سرور و حساب کاربری‌ای در کار نیست.

## ✨ امکانات

| بخش | توضیح |
|---|---|
| 📊 داشبورد | نمای کلی امروز؛ وقتی ماژول مالی خاموش است، بهره‌وری، حال هفته، خواب/ورزش و یادداشت‌های سنجاق‌شده را نشان می‌دهد |
| 📅 روز جاری | تایم‌لاین روز، تسک‌های زمان‌دار، ردیاب عادت‌ها، اطلاعات پایه روز (خواب، ورزش، بیرون) و «بازتاب پایان روز» |
| 🗃️ بک‌لاگ | تسک‌های بدون روز مشخص + ماتریس آیزنهاور (مهم/فوری) با درگ‌ان‌دراپ |
| 💰 مالی *(اختیاری)* | ثبت درآمد/هزینه به تومان، دسته‌بندی‌ها، بودجه ماهانه شمسی، نمودار دسته‌ها — با یک کلیک مخفی/نمایان می‌شود |
| ✅ وظایف | برد کانبان (انجام‌نشده / در حال انجام / انجام‌شده)، اولویت، برچسب، زیروظیفه، سررسید، ددلاین و ویرایش درجا |
| 🗓️ تقویم | تقویم شمسی (جلالی) با رویدادها و سررسید وظایف، دستور کار ۱۴ روزه، هیت‌مپ نمره روز و مبدل تاریخ |
| 🔁 عادت‌ها | عادت‌های هفتگی با هدف تعداد در هفته، رنگ، استریک و **بایگانی** |
| 📝 یادداشت‌ها | یادداشت رنگی با سنجاق و برچسب |
| 📈 گزارش‌ها | دو حالت هوشمند: گزارش مالی کامل (وقتی مالی فعال است) یا **گزارش زندگی** — بهره‌وری، عادت‌ها، حال، نمره، خواب و ورزش |
| ⚙️ تنظیمات | تم روشن/تیره، واحد پول، شروع هفته، تقویم سربرگ، مدیریت عادت‌ها و دسته‌ها، پشتیبان‌گیری پیشرفته، یادآور شبانه |

## 💾 پشتیبان‌گیری

- **دانلود پشتیبان JSON** با نام فایل تاریخ‌دار شمسی
- **بازیابی راحت:** انتخاب فایل، درگ‌ان‌دراپ، یا چسباندن متن JSON — همیشه با **پیش‌نمایش محتوا** قبل از تأیید نهایی
- **پشتیبان‌های خودکار:** برنامه هر چند ساعت یک اسنپ‌شات امن (حداکثر ۳ نسخه) در مرورگر نگه می‌دارد؛ حتی بعد از «پاک کردن همه داده‌ها» قابل بازیابی‌اند
- نمایش حجم مصرف‌شده حافظه مرورگر + هشدار هوشمند پر شدن حافظه

## 🛠️ فناوری‌ها

- **React 19** + **TypeScript** + **Vite 7**
- **Tailwind CSS 4** — استایل‌دهی
- **framer-motion** — انیمیشن
- **react-router (HashRouter)** — مسیریابی سازگار با GitHub Pages
- تقویم جلالی با پیاده‌سازی داخلی (بدون وابستگی خارجی)
- لود تنبل صفحات + مرز خطا (Error Boundary) برای پایداری بیشتر
- فونت **وزیرمتن**

## 🚀 اجرای محلی

```bash
npm ci        # نصب وابستگی‌ها
npm run dev   # سرور توسعه → http://localhost:5173
```

سایر دستورات:

```bash
npm run lint      # بررسی کیفیت کد (ESLint)
npm run build     # تایپ‌چک + بیلد پروداکشن در dist/
npm run preview   # پیش‌نمایش خروجی بیلد
```

## 📦 استقرار خودکار (GitHub Pages)

با هر push روی شاخه `main` (یا `master`)، ورک‌فلوی [`deploy.yml`](.github/workflows/deploy.yml) به‌صورت خودکار:

1. وابستگی‌ها را با `npm ci` نصب می‌کند
2. لینت و تایپ‌چک + بیلد را اجرا می‌کند
3. خروجی `dist/` را روی GitHub Pages مستقر می‌کند

**پیش‌نیاز (فقط یک بار):** در تنظیمات ریپو مسیر زیر را ست کنید:

```
Settings → Pages → Build and deployment → Source: GitHub Actions
```

پس از اولین اجرای موفق، برنامه روی آدرس زیر در دسترس است:

```
https://<username>.github.io/<repo>/
```

## 🔒 حریم خصوصی
