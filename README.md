# میزکار زندگی 🗂️

> وب‌اپ شخصی فارسی برای مدیریت یکپارچه‌ی مالی، وظایف، تقویم شمسی، عادت‌ها و یادداشت‌ها — کاملاً آفلاین و در مرورگر خودتان.

تمام داده‌ها فقط در `localStorage` مرورگر ذخیره می‌شوند؛ هیچ سرور و حساب کاربری‌ای در کار نیست.

## ✨ امکانات

| بخش | توضیح |
|---|---|
| 📊 داشبورد | نمای کلی مالی ماه، وظایف باز و عقب‌افتاده، نمودار هزینه/درآمد ۱۴ روزه |
| 📅 امروز | تایم‌لاین روز، تسک‌های زمان‌دار، ردیاب عادت‌ها و «بازتاب پایان روز» (حال‌وهوا، خواب، ورزش و نمره روز) |
| 🗃️ بک‌لاگ | تسک‌های بدون روز مشخص + ماتریس آیزنهاور (مهم/فوری) |
| 💰 مالی | ثبت درآمد/هزینه به تومان، دسته‌بندی‌ها، بودجه ماهانه شمسی، نمودار دسته‌ها |
| ✅ وظایف | برد کانبان (انجام‌نشده / در حال انجام / انجام‌شده)، اولویت، برچسب، زیروظیفه، ددلاین |
| 🗓️ تقویم | تقویم شمسی (جلالی) با رویدادها و سررسید وظایف |
| 🔁 عادت‌ها | عادت‌های هفتگی با هدف تعداد در هفته، رنگ و بایگانی |
| 📝 یادداشت‌ها | یادداشت رنگی با سنجاق و برچسب |
| 📈 گزارش‌ها | آمار و روند عادت‌ها، وظایف، مالی و بازتاب‌های روزانه |
| ⚙️ تنظیمات | تم روشن/تیره، واحد پول، فعال/غیرفعال‌سازی بخش مالی، پشتیبان‌گیری/بازیابی JSON، یادآور شبانه |

## 🛠️ فناوری‌ها

- **React 19** + **TypeScript** + **Vite 7**
- **Tailwind CSS 4** — استایل‌دهی
- **framer-motion** — انیمیشن
- **react-router (HashRouter)** — مسیریابی سازگار با GitHub Pages
- تقویم جلالی با پیاده‌سازی داخلی (بدون وابستگی خارجی)
- فونت **وزیرمتن**

## 🚀 اجرای محلی

```bash
npm ci        # نصب وابستگی‌ها
npm run dev   # سرور توسعه → http://localhost:5173
```

سایر دستورات:

```bash
npm run lint      # بررسی کیفیت کد (ESLint)
npm run build     # تایپ‌چک + بیلد پروداکشن در dist/
npm run preview   # پیش‌نمایش خروجی بیلد
```

## 📦 استقرار خودکار (GitHub Pages)

با هر push روی شاخه `master`، ورک‌فلوی [`deploy.yml`](.github/workflows/deploy.yml) به‌صورت خودکار:

1. وابستگی‌ها را با `npm ci` نصب می‌کند
2. لینت و تایپ‌چک + بیلد را اجرا می‌کند
3. خروجی `dist/` را روی GitHub Pages مستقر می‌کند

**پیش‌نیاز (فقط یک بار):** در تنظیمات ریپو مسیر زیر را ست کنید:

```
Settings → Pages → Build and deployment → Source: GitHub Actions
```

پس از اولین اجرای موفق، برنامه روی آدرس زیر در دسترس است:

```
https://<username>.github.io/<repo>/
```

## 🔒 حریم خصوصی

همه‌چیز آفلاین است؛ داده‌ها هرگز از مرورگر شما خارج نمی‌شوند. برای جابه‌جایی بین دستگاه‌ها از **پشتیبان‌گیری JSON** در بخش تنظیمات استفاده کنید.
