# میزکار زندگی 🗂️

> وب‌اپ شخصی فارسی برای مدیریت یکپارچه‌ی وظایف، تقویم شمسی، عادت‌ها، یادداشت‌ها و **تحلیل نمره روزها** — کاملاً آفلاین و در مرورگر خودتان.

تمام داده‌ها فقط در `localStorage` مرورگر ذخیره می‌شوند؛ هیچ سرور، حساب کاربری یا ارسال داده‌ای در کار نیست.

## ⭐ نمره روز (۰ تا ۱۰ با یک رقم اعشار)

- هر روز می‌توانید به روزتان نمره بدهید: نوار لغزان با گام `۰٫۱` **و** ورود دستی عدد (مثلاً `۷٫۵`).
- عدد را می‌توانید با ارقام فارسی یا لاتین و با جداکننده‌ی `٫` یا `.` بنویسید؛ نمره همیشه در بازه ۰ تا ۱۰ و با یک رقم اعشار ذخیره می‌شود.
- خانه‌های تقویم با هیت‌مپ نمره رنگ می‌گیرند و در «تحلیل روزها» میانگین، میانه، نوسان و بهترین/ضعیف‌ترین روز محاسبه می‌شود.
- «ثبت نشده» یعنی نمره‌ای برای آن روز وارد نشده است — این حالت در همه‌ی خروجی‌های متنی صریح نوشته می‌شود.

## 📋 خروجی متنی از روزها

در صفحه «تحلیل روزها» می‌توانید:

- **۱ روز یا چند روز** را انتخاب کنید — دستی، همه‌ی روزهای بازه، فقط روزهای دارای نمره، فقط روزهای دارای توضیحات، روزهای عالی/ضعیف، یا **انتخاب تصادفی** (مثلاً ۱۰ روز تصادفی از میان روزهای دارای نمره).
- خروجی را **با نمره** یا **بدون نمره** (فقط توضیحات و یادداشت‌ها) بسازید.
- هر بخش را جداگانه روشن/خاموش کنید: نمره، حال روز، توضیحات، دستاورد/بهبود/درس/قدردانی، خواب و ورزش، عادت‌ها، تسک‌ها و رویدادها.
- فیلدهای خالی همیشه با عبارت‌های **«ثبت نشده»** یا **«خالی»** در متن می‌آیند تا هیچ چیز مبهم نماند.
- متن را **کپی** کنید یا به‌صورت **TXT** و **CSV** دانلود کنید؛ پیش‌نمایش کامل پیش از کپی نمایش داده می‌شود.

## 🕐 ساعت‌ها

همه‌ی ساعت‌ها در کل برنامه **۲۴ ساعته** و در قالب `HH:MM` (از `۰۰:۰۰` تا `۲۳:۵۹`) هستند؛ هیچ‌جا AM/PM نمایش داده نمی‌شود. ورودی ساعت هم متن آزاد (با پذیرش ارقام فارسی) و هم فهرست کشویی ساعت/دقیقه دارد.

## 💾 پشتیبان‌گیری

- **دانلود پشتیبان JSON** با نام فایل تاریخ‌دار شمسی
- **بازیابی راحت:** انتخاب فایل، درگ‌ان‌دراپ، یا چسباندن متن JSON — همیشه با **پیش‌نمایش محتوا** قبل از تأیید نهایی
- **پشتیبان‌های خودکار:** برنامه هر چند ساعت یک اسنپ‌شات امن (حداکثر ۳ نسخه) در مرورگر نگه می‌دارد؛ حتی بعد از «پاک کردن همه داده‌ها» قابل بازیابی‌اند
- نمایش حجم مصرف‌شده حافظه مرورگر + هشدار هوشمند پر شدن حافظه
- همه‌ی داده‌های ذخیره‌شده یا بازیابی‌شده از یک لایه اعتبارسنجی (`sanitize`) عبور می‌کنند؛ فایل خراب یا قدیمی برنامه را از کار نمی‌اندازد

## 🚀 اجرای محلی

```bash
npm ci        # نصب وابستگی‌ها
npm run dev   # سرور توسعه → http://localhost:5173
```

سایر دستورات:

```bash
npm run lint      # بررسی کیفیت کد (ESLint)
npm run build     # تایپ‌چک + بیلد پروداکشن در dist/
npm run preview   # پیش‌نمایش خروجی بیلد
```

## 📦 استقرار خودکار (GitHub Pages)

با هر push روی شاخه `main` (یا `master`)، ورک‌فلوی [`deploy.yml`](.github/workflows/deploy.yml) به‌صورت خودکار:

1. وابستگی‌ها را با `npm ci` نصب می‌کند
2. لینت و تایپ‌چک + بیلد را اجرا می‌کند
3. خروجی `dist/` را روی GitHub Pages مستقر می‌کند

**پیش‌نیاز (فقط یک بار):** در تنظیمات ریپو مسیر زیر را ست کنید:

```
Settings → Pages → Build and deployment → Source: GitHub Actions
```

پس از اولین اجرای موفق، برنامه روی آدرس زیر در دسترس است:

```
https://<username>.github.io/<repo>/
```
