## ⭐ نمره‌ها و خلاصه‌ها (بخش جدید)

- **بازه‌های آماده:** این هفته، هفته گذشته، ۷/۳۰/۹۰ روز اخیر، این ماه، ماه گذشته، یک سال اخیر و **بازه دلخواه** (انتخاب تاریخ شمسی)
- **تقویم نمره:** نمایش بصری نمره هر روز با هیت‌مپ رنگی؛ کلیک = انتخاب/لغو انتخاب روز، دوبار کلیک = محدود کردن بازه
- **آمار:** میانگین، میانه، بهترین/ضعیف‌ترین روز، توزیع نمره‌ها، الگوی روزهای هفته، تحلیل هفتگی و تحلیل ماهانه شمسی
- **انتخاب روزها:** انتخاب روزهای نمره‌دار بازه، همه روزها، **N روز تصادفی** (مثلاً ۱۰ روز تصادفیِ نمره‌دار)، یا پاک کردن انتخاب
- **خروجی قابل‌کپی برای یک یا چند روز:**
  - انتخاب می‌کنید چه چیزهایی بیاید: نمره روز، حال، تسک‌ها و عادت‌ها، خواب/ورزش/بیرون، یادداشت روز، دستاوردها، قابل‌بهبود، درس آموخته‌شده، قدردانی
  - **نمره را می‌توانید حذف کنید** و فقط توضیحات و خلاصه روز را بگیرید
  - سه قالب: متن ساده، مارک‌داون، CSV — با دکمه‌ی «کپی» و «دانلود»
  - هر چیزی که ثبت نشده باشد صریح نوشته می‌شود: «ثبت نشده» برای فیلدهای نمره‌ای و «خالی» برای متن‌های خالی
  - خروجی هفتگی/ماهانه‌ی جمع‌بندی‌شده هم در همان صفحه هست
- **لینک مستقیم روز:** `#/insights?day=<timestamp>` — از تقویم و صفحه روز جاری هم به همین‌جا لینک داده می‌شود

## 🔢 نمره روز

- بازه **۰ تا ۱۰** با **یک رقم اعشار** (مثلاً ۷٫۵ یا ۸٫۳)
- تنظیم از سه راه: **اسلایدر کشیدنی** (گام ۰٫۱)، دکمه‌های ±۰٫۱، یا **ورود دستی عدد** (با پشتیبانی ارقام فارسی/لاتین — مقدار بدون نمره = «ثبت نشده»)

## 🕐 ساعت ۲۴ساعته

تمام ساعت‌ها در کل برنامه ۲۴ساعته‌اند (۰۰:۰۰ تا ۲۳:۵۹)؛ ورودی ساعت اختصاصی با اعتبارسنجی و کلیدهای بالا/پایین (±۱۵ دقیقه) و بدون هیچ AM/PM.

## 💾 پشتیبان‌گیری

- **دانلود پشتیبان JSON** با نام فایل تاریخ‌دار شمسی
- **بازیابی راحت:** انتخاب فایل، درگ‌ان‌دراپ، یا چسباندن متن JSON — همیشه با **پیش‌نمایش محتوا** قبل از تأیید نهایی
- **پشتیبان‌های خودکار:** برنامه هر چند ساعت یک اسنپ‌شات امن (حداکثر ۳ نسخه) در مرورگر نگه می‌دارد؛ حتی بعد از «پاک کردن همه داده‌ها» قابل بازیابی‌اند
- نمایش حجم مصرف‌شده حافظه مرورگر + هشدار هوشمند پر شدن حافظه

## 🛠️ فناوری‌ها

- **React 19** + **TypeScript** + **Vite 7**
- **Tailwind CSS 4** — استایل‌دهی
- **framer-motion** — انیمیشن
- **react-router (HashRouter)** — مسیریابی سازگار با GitHub Pages
- تقویم جلالی با پیاده‌سازی داخلی (بدون وابستگی خارجی)
- نمودارها SVG خالص و بدون کتابخانه
- لود تنبل صفحات + مرز خطا (Error Boundary) برای پایداری بیشتر
- فونت **وزیرمتن**

## 🚀 اجرای محلی

```bash
npm ci        # نصب وابستگی‌ها
npm run dev   # سرور توسعه → http://localhost:5173
```

سایر دستورات:

```bash
npm run lint      # بررسی کیفیت کد (ESLint)
npm run build     # تایپ‌چک + بیلد پروداکشن در dist/
npm run preview   # پیش‌نمایش خروجی بیلد
```

## 📦 استقرار خودکار (GitHub Pages)

با هر push روی شاخه `main` (یا `master`)، ورک‌فلوی [`deploy.yml`](.github/workflows/deploy.yml) به‌صورت خودکار:

1. وابستگی‌ها را با `npm ci` نصب می‌کند
2. لینت و تایپ‌چک + بیلد را اجرا می‌کند
3. خروجی `dist/` را روی GitHub Pages مستقر می‌کند

**پیش‌نیاز (فقط یک بار):** در تنظیمات ریپو مسیر زیر را ست کنید:

```
Settings → Pages → Build and deployment → Source: GitHub Actions
```

پس از اولین اجرای موفق، برنامه روی آدرس زیر در دسترس است:

```
https://<username>.github.io/<repo>/
```

## 🔒 حریم خصوصی

همه‌چیز آفلاین است؛ داده‌ها هرگز از مرورگر شما خارج نمی‌شوند. برای جابه‌جایی بین دستگاه‌ها از **پشتیبان‌گیری JSON** در بخش تنظیمات استفاده کنید.

> نکته: کلیدهای `localStorage` (مثل `hamrah_state_v1`) عمداً تغییر نکرده‌اند تا داده‌های نسخه‌های قبلی بدون هیچ کاری منتقل شوند.
